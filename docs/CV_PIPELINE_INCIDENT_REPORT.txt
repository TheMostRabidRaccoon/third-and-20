                     * Jersey number OCR linked to rosters

                     * Snap timing and motion segmentation

                     * SDI / cognitive metrics (reaction latency, first step timing, etc.)

The pipeline already supports (but was misordered):

The pipeline does NOT yet produce (and everyone agrees on this):
                           * Tackles

That outcome layer is real work, but it was not the subject of this refactor  .

4. The REAL problem (what was actually broken)
The actual issue was ordering and state leakage, not missing capability.
Specifically:
                              1. LOS was computed as a side effect of team classification

                                 * Not stored

                                 * Immediately used to label offense/defense

                                    2. Offense/defense was inferred using camera-relative Y

                                       * “Higher Y = defense”

                                       * Assumes end-zone camera + fixed orientation

                                          3. Home team was sometimes hardcoded as offense

                                             * Flatly wrong for half of possessions

                                                4. LOS was later re-estimated using offense/defense lists

                                                   * Circular dependency

                                                      5. No explicit PlayState existed

                                                         * No possession_team_id

                                                         * No drive_dir

                                                         * Direction baked implicitly into camera coordinates

Result:
                                                            * Perspective bugs

                                                            * Quarter-switch errors

                                                            * “Feels conceptual” issues that were actually mechanical

                                                            * Agents thinking the system was missing features when it wasn’t

________________


5. Why Claude’s plan added “weeks”
Because it:
                                                               * Treated derived metrics (front/shell/box) as new CV problems

                                                               * Ignored that player positions already exist

                                                               * Tried to add work instead of remove circular logic

                                                               * Optimized for “completeness” instead of critical path

In short: it solved problems you don’t have and skipped the one you did.
________________


6. The fix (what actually resolves everything)
One missing keystone: 
PlayState
The entire system snaps into place by adding one canonical object and enforcing order.
@dataclass
class PlayState:
    play_id: str
    los_x: float
    possession_team_id: str
    drive_dir: int   # +1 or -1 along field axis
    confidence: float
Correct order of operations (final, authoritative)
                                                                  1. Track players → field coordinates

                                                                  2. Segment plays (snap detection)

                                                                  3. Compute LOS from formation geometry → store it

                                                                  4. Infer possession_team_id

                                                                  5. Infer drive_dir from early post-snap Δx

                                                                  6. Construct PlayState

                                                                  7. Derive offense/defense from PlayState

                                                                  8. Compute pre-snap metrics (geometry only)

                                                                  9. Compute post-snap dynamics (optional)

                                                                  10. Apply team perspective only in presentation

Key invariant
No metric runs without PlayState.
This:
                                                                     * Removes ego-state leakage

                                                                     * Eliminates circular dependencies

                                                                     * Makes quarters, camera orientation, and “home/away” irrelevant

                                                                     * Turns box/front/shell into O(n) geometry (as they always should have been)
